# 🏋️ GymGym - Приложение для записей тренировок

Простое React Native приложение для ведения записей о походах в тренажерный зал.

## 📱 Функционал

- **Список тренировок** - просмотр всех тренировок с датами
- **Текущая тренировка** - добавление подходов с таймером
- **SQLite хранение** - все данные сохраняются на устройстве
- **Автоматическая дата** - берется из телефона по Гринвичу

## 🎯 Экраны

### 1. Список тренировок
- Отображает все сохраненные тренировки
- Сортировка по дате (новые сверху)
- Возможность удаления тренировок
- Кнопка создания новой тренировки

### 2. Текущая тренировка
- **Поле ввода** - название упражнения
- **Поля для веса и повторений** - опциональные
- **Таймер** - старт/стоп для измерения времени подхода
- **Список подходов** - уже выполненные подходы текущей тренировки

## 🛠 Технологии

- React Native 0.73+
- React Navigation 6
- SQLite (react-native-sqlite-storage)
- JavaScript (ES6+)

## 🚀 Установка

Смотри подробный туториал в [TUTORIAL.md](TUTORIAL.md)

```bash

# Установи зависимости
```

## 💾 База данных

Схема базы данных основана на [gymgym](https://github.com/iamsoloma/gymgym):

- **trainings** - тренировки (id, date)
- **exercises** - упражнения (id, name)
- **sets** - подходы (id, training_id, exercise_id, weight_kg, reps, started_at, finished_at)

## 📝 Пример использования

1. Открой приложение
2. Нажми "Новая тренировка"
3. Введи название упражнения (например: "Жим штанги")
4. Введи вес (например: 60)
5. Введи повторения (например: 10)
6. Нажми "Старт" - таймер начнет отсчет
7. Выполни подход
8. Нажми "Стоп" - подход сохранится
9. Повтори для следующего подхода
10. Вернись к списку тренировок
